# Features and roadmap

## Built and included in the ZIP

- Six validated, NASA-linked mission entries.
- Responsive mission explorer with filtering and text search.
- Learn-more dialog with mission history and supporting facts.
- Three-question, single-answer quiz on each mission.
- Immediate feedback, results, retry, and progress reset.
- Local browser completion tracking without accounts.
- Documentation, mission-source ledger, asset instructions, and tests.

## Represented by original design links, not implemented here

- The animated launch screen and full mobile game progression.
- Character selection, cinematic scenes, 3D rover scenes, and any original 3D gameplay.
- Original Figma-specific app interactions, assets, and layouts.

## Proposed next milestones

1. Add both official images, then confirm team spellings and logo permissions.
2. Review all educational descriptions with the researcher and developer.
3. Publish the static companion demo via GitHub Pages and add the URL to README.
4. Decide whether the original game source is ready and authorized for inclusion.
5. Expand planet coverage or interactive learning exercises based on classroom feedback.
6. Improve offline font handling, screen-reader testing, and automated browser tests.
