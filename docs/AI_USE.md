# AI use and content disclosure

## Creative workflow

The existing project materials identify Figma, Filmora, Google Flow, and ChatGPT as tools used during the team's design and media workflow. The team's published video or final submission should use its own accurate footage and asset attribution record.

## What was AI-assisted for this GitHub starter

The companion website code, its presentation text, quiz question drafts, and the repository documentation were prepared with AI assistance, then organized against the public project context and NASA mission references. Team roles, project identity, and the two intended screenshots come from materials supplied for this repository.

## What is *not* claimed

- No AI model is running in the website.
- Mission answers are not automatically evaluated by an LLM; they are selected from reviewed JSON.
- There is no real-time NASA API, model-generated 3D renderer, or deployed production game in the provided source.
- No fabricated user testing, metrics, or external awards are asserted.

## Review before submission

Team members should verify names, factual claims, image rights, AI-generated footage disclosure, and the scope of implemented features. For media attribution, record titles, owners, links, and any generation or editing methods for clips used in the final video.
