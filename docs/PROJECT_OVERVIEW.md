# Project overview

## One-sentence description

AstroMind is a NASA Space Apps 2026 educational storytelling project that helps younger space enthusiasts understand the missions, equipment, and discoveries of robotic and crewed exploration beyond Earth.

## Why it exists

Rovers, landers, and probes can be forgotten when their mission headlines fade. The project connects a piece of hardware to its scientific purpose, its discoveries, and its eventual fate.

## Audience

School-age students, educators, and curious beginners; the writing aims to be approachable without inventing scientific details.

## Project forms

1. **Original game concept** — visual, story-driven mobile interaction, documented in the linked Figma prototype and demo video.
2. **This repository's companion web demo** — responsive, standalone educational mission exploration and quizzes. It is not the original game source code and does not reproduce its 3D mechanics.

## Learning loop

Explore a destination → choose a mission → read its story → examine evidence and sources → answer three questions → track completion locally.

## Boundaries

- NASA-sourced summaries are curated, not a real-time NASA data feed.
- A completed mission is not necessarily physically abandoned in place. Cassini and Voyager show contrasting mission outcomes.
- No accounts, hosted database, analytics, or live data are collected by this website.

## Intended outcomes

- Make planetary science and mission history accessible.
- Encourage readers to use primary-source NASA references.
- Help students distinguish an inactive rover, a planned mission finale, and an operational probe.
